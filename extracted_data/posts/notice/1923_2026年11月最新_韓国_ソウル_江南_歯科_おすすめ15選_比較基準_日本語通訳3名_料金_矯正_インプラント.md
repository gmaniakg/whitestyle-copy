<h3 class="wb-ka wbka" style="font-size:19px;font-weight:bold;color:#091326;margin:0 0 18px 0;">日本人患者様 よくあるご質問 Q&amp;A（4選）</h3>
<p class="wb-ka wbka" style="font-size:15.5px;margin:0 0 8px 0;color:#091326;"><strong>Q1. 日本語通訳は予約時だけですか？ 診療中や会計時も同席してもらえますか？</strong></p>
<p class="wb-ka wbka clinical-faq-answer" style="font-size:15.5px;margin:0 0 20px 0;color:#334155;line-height:1.95;">専任日本語医療通訳スタッフ3名が院内に常駐しているため、渡韓前のLINE（ID: whitestyle1）または直通電話（+82-10-3046-5010）での事前相談から、来院当日の受付・3D CT検査・院長カウンセリング・施術・会計・帰国後のフォローまで一貫して日本語でサポートいたします。</p>

<p class="wb-ka wbka" style="font-size:15.5px;margin:0 0 8px 0;color:#091326;"><strong>Q2. 渡韓日数が2泊3日しかありませんが、1DAYホワイトニングや最小削除ラミネートは受けられますか？</strong></p>
<p class="wb-ka wbka clinical-faq-answer" style="font-size:15.5px;margin:0 0 20px 0;color:#334155;line-height:1.95;">1DAYオフィスホワイトニングは約60分・1回の来院で完結するため1泊2日でも施術可能です。無削除ゼロシェルや0.1〜0.2mm最小削除ラミネートは院内専属歯科技工所の連携により最短2〜3回来院でのご案内が可能ですので、渡韓前にLINEでお口元の写真をお送りいただければ日程をお見積りいたします。</p>

<p class="wb-ka wbka" style="font-size:15.5px;margin:0 0 8px 0;color:#091326;"><strong>Q3. 韓国での歯科矯正やインプラントは、帰国後に担当医が変わったり追加料金が出たりしませんか？</strong></p>
<p class="wb-ka wbka clinical-faq-answer" style="font-size:15.5px;margin:0 0 20px 0;color:#334155;line-height:1.95;">ホワイトスタイル歯科は1994年開院以来、金俊憲病院長・李奉珍代表院長・朴宣恵院長の3名体制で主治医変更なしを徹底しています。歯列矯正は診断費・装置費・調整料・保定装置代を含むトータルフィー総額制を採用し、インプラント・骨移植の追加範囲も3D CT診断後に事前書面提示いたします。</p>

<p class="wb-ka wbka" style="font-size:15.5px;margin:0 0 8px 0;color:#091326;"><strong>Q4. クリニックの正確な住所・休診日・直通窓口を教えてください。</strong></p>
