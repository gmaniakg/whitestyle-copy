<div class="wb-ka wbka" style="margin:28px 0 36px 0;background-color:#ffffff;border:1px solid #cbd5e1;padding:28px 26px;border-radius:8px;"><h3 class="wb-ka wbka" style="margin:0 0 14px 0;font-size:20px;font-weight:700;color:#0f172a;line-height:1.5;">[언론보도 전문] 우리동네 모범납세자는 누구? ‘병원’편 (모범납세자 선정)</h3><p class="wb-ka wbka" style="margin:0 0 22px 0;font-size:14.5px;color:#475569;padding-bottom:14px;border-bottom:1px solid #e2e8f0;line-height:1.85;"><strong>매체명:</strong> 비즈니스워치 &nbsp;|&nbsp; 입력 2015.03.11(수) 14:41 &nbsp;|&nbsp; <strong>도움말:</strong> 화이트스타일치과의원 김준헌 병원장 (치의학박사)</p><div class="wb-ka wbka" style="padding:22px 24px;background-color:#f8fafc;border-left:4px solid #0284c7;font-size:16px;color:#0f172a;line-height:2.05;"><p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">스마트폰에서 &#x27;맛집&#x27;을 검색해보면 지역과 메뉴 별로 다양한 음식점이 나옵니다. 그런데 막상 가보면 실망스러울 때도 많은데요. 주방장의 정성 대신 얄팍한 상술이 &#x27;맛집&#x27;으로 둔갑했기 때문입니다.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">몸이 아플 때도 마찬가지입니다. 내가 찾아갈 병원의 원장이 돌팔이인지, 돈만 밝히는지 도무지 확인할 길이 없죠. 진정한 맛집이나 병원을 걸러낼 방법은 과연 없는 걸까요. 최근 국세청이 인증한 &#x27;모범납세자&#x27;에서 힌트를 찾을 수 있습니다. 경기가 어려운 상황에서도 탈세의 유혹을 뿌리치고 성실하게 세금을 납부한 자영업자들입니다.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">그들이 최고의 맛이나 의료 서비스를 제공한다고 100% 장담하긴 어렵지만, 적어도 양심을 지키고 있다는 점은 확실합니다. 세금을 잘 내면서 국가 경제와 지역 발전에 이바지하고 있는 맛집과 병원을 소개합니다.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲하늘병원(답십리)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">하늘병원 조성연 원장은 스포츠 의학 분야를 개척하고 국내에 알린 인물. 다수의 스포츠 종목 선수 및 관련 단체의 역량 증진에 기여. 비수술적 치료(주사 치료 및 재활 치료)를 통해 환자들에게 수준 높은 의료 서비스를 제공.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲소망정형외과의원(신당동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">정형외과 전문의로 어려운 여건 속에서도 성실히 지역주민에 대한 의료서비스 제공과 각종 사회활동을 수행. 증빙에 의한 투명한 장부기장을 통해 성실한 납세의무를 이행. 비행청소년 선도 및 의료선교활동을 지속적으로 수행.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲21세기병원(묵동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">척추와 관절 토탈케어(Total care)를 슬로건으로 환자 개인 맞춤형 진료 및 질환 예방에서 재활까지 관리하며, 비수술적 치료를 원칙으로 진료. 누구나 항상 믿고 쉽게 찾을 수 있는 척추관절병원.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲신촌연세병원(신수동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">세분화된 진료과와 전문센터, 20여명의 우수한 전문의료진, 200여명의 직원들과 함께 특성화된 맞춤형 진료로 양질의 진료서비스를 제공. 해외아동 후원과 마포구 관내 지역 저소득층을 후원하는 사랑의 쌀 나눔행사 및 후원금 전달.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲종로하나로치과의원(청진동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">2011년 4월 개원이래 성실납세로 국가재정과 세정발전에 기여. 한국국제협력단(KOICA) 소속 정부파견 치과의사로 페루(남미) 제3병원에 파견, 페루 원주민과 극빈자 봉사활동 동참.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲임계순 내과(북가좌동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">&#x27;환자도 가족이다&#x27;는 경영이념으로 지역 건강증진에 기여. 친절과 나눔을 실천하고 동반자적 고용관계 및 공정하고 투명한 기업운 영으로 국세행정 운영에 일조.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲주원장한의원(잠실동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">&#x27;8체질진단&#x27; 전문한의원으로 체질치료를 통해 지역주민의 건강증진과 체질의학 연구로 한의학 발전에 기여. 투명한 경영을 통하여 납세의무를 성실하게 이행.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲안병석 치과(행당동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">1996년 4월 성동구 행당동에 치과를 개원해 18년간 나눔과 사회공헌을 실천. 소외된 계층을 위한 정기적인 후원과 재능기부를 통해 형편이 어려워 치과방문이 힘든 환우들을 위한 치료.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲우리가정의원(마장동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">1992년 9월 개원 후 22년 이상 한 지역에서 주치의로서 의료활동. 2000년부터 성동구 의사회 보람장학회 참여해 장학금 전달. 마장동과 사근동 불우이웃을 돕고 있음.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲서울정&amp;오치과의원(상도동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">2009년에 동작구 상도동 성대시장 부근에 개원한 치과로 대표원장을 포함해 5명이 일하고 있음. 지역사회 주민들의 구강상태를 책임진다는 자세로 최상의 진료를 제공.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲최현주 영상의학과의원(동소문동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">정밀한 유방암, 자궁암 진단 및 초음파 검진을 통한 조기판독으로 여성 질병 예방 및 치료에 기여. 다년간 외국노동자 진료 봉사활동에 참여, 사랑의 장기기증재단 등 후원.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲현대치과(쌍문동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">1984년 7월부터 30여년간 헌신적 자세와 친절한 진료로 지역 주민의 건강을 돌보고 있음.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲은평연세병원(구산동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">진단에서 수술까지 원스톱 진료하는 수술전문병원. 2006년 개원 이래 최고의 전문성을 갖춘 외과수술과 조기진단 및 내시경적 치료.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲압구정성모안과의원(신사동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">28년 전통, 국내 최초로 라섹(LASEK)수술 도입. 2000년 미국과 일본 등 세계의 유수학회에서 임상결과를 발표해 국제적으로 주목을 받음.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲지성한의원(성내동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">30여년 간 한의원을 운영하면서 사회봉사의 일환으로 종합사회복지관에서 저소득층 노인들을 대상으로 20여년 간 무상진료봉 사. 보건복지부 청소년 건강상담 및 금연침 무료시술 사업에 적극 참여, 장학금 기부.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲계명치과(성내동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">1995년 5월 서울 강동구 성내동에 계명치과를 개업해 20년간 운영하면서 지역의 고용증진과 사회발전에 기여. 부가가치세 성실신고로 국세행정과 세수확보에 기여.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲강동서울의원(길동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">2008년 개업 후 수년간 병원을 운영하면서 지역사회의 건강증진에 기여. 지급명세서 성실제출 등 각종 국세행정에 적극 협조.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲맑은숲 한초당한의원(신도림동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">2007년 개업 후 국민보건 향상 및 출산률 증진을 위한 의료활동 및 저소득층 무료진료와 금연침 시술 등 사회봉사활동. 부인과 난임위주 진료를 통한 국가 출산률 향상에 기여. 투명한 거래 및 회계처리를 통한 성실한 신고납부.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲연세무지개치과의원(고척동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">1994년부터 연세대학교 치과병원 레지턴트를 시작으로 보다 나은 치보건 서비스 제공을 위해 연구. 투명한 회계처리를 통해 국세행정에 협조. 종사직원 복지 향상 및 고용안정 노력.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲대항병원(방배동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">대장·항문 분야 전문병원으로 1990년 개원 이후 25년간 정직한 진료와 최상의 의료수준으로 연구와 임상을 통해 국내 최고 수준으로 성장. 2008년 이후 연속으로 보건복지부 지정 대장·항문 전문병원으로 지정. 2001년부터 임직원이 참여하는 사랑나누미 봉사단을 결성해 환경, 의료, 복지 등 각 분야에서도 다양한 활동 전개.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲최병기 치과의원(공릉동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">최병기 원장은 열린의사회 회장으로 국내외 외료봉사활동으로 국위선양. 지역사회의 소외된 이웃들을 위해 봉사활동은 물론 지속적인 장학금 전달과 자선기부활동으로 사회에 공헌.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲여디디야치과의원(낙성대동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">치아교정을 통해 환자들의 자신감과 아름다운 미소를 찾아주고 있음. 투명한 경영을 통하여 납세의무를 성실하게 이행.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲은평연세치과의원(갈현동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">1992년 8월 설립 이래 지역사회의 구강보건에 최선을 다하는 의료 기관. 납세의무를 성실히 이행해 국가재정과 성실한 납세풍토 조성에 기여.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲고범연 치과의원(대치동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">1995년 개원해 따뜻한 마음과 정성으로 진료하는 곳으로 환자들로부터 신뢰를 얻고 있는 병원. 20년 간 병원스탭이 바뀌지 않고, 최상의 진료 결과를 유지하고 있음. 생활이 어려운 안면기형환자를 지속적으로 무료진료봉사.</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">▲화이트스타일치과의원(역삼동)</p>
<p class="wb-ka wbka" style="margin:0 0 20px 0;line-height:2.05;">1994년 개원, 불우 청소년 교정지원사업에 적극 참여해 부정교합 등 치아 컴플렉스로 본인의 꿈을 펼치지 못하고 있는 어려운 형편의 학생들의 무료치아교정치료를 위해 힘쓰고 있음. 2010년부터 강남구 외국인환자 유치협력기관으로 선정.</p>
